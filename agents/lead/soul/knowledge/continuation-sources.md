Start with docs/operating-team-migration.md for scope, owners, and completion
criteria. Read current aw tasks and conversations before interpreting old
handover notes. Each release needs an exact source tag, published artifact,
installed version, and relevant execution evidence; a green source checkout is
not a published installation.

On the operator's development machine, ~/awebai/bookshelf/README.md identifies
the current strategy authority. Bookshelf is private strategy; repository
contracts and published code define current product behavior. Read the current
authority before using an older dated architecture proposal as an instruction.

The first operating rollout keeps detailed disposable evidence under
/tmp/oats-fresh-review and published artifact checks under
/tmp/oats-published-v0.22.3. These temporary paths are useful during handover,
not durable product storage. Promote only the needed conclusions and source
references into the maintained rollout record or reviewed knowledge.

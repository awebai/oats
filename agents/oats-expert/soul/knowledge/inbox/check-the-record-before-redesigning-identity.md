Three rounds of design discussion about global identities for OATS instances produced a careful conclusion that missed the recorded decision: resident identities served through session grants (a product decision from a month earlier), a shipped `aw id grant` surface, and a working messaging capability in a sibling deployment that implements the seam. Each problem the discussion enumerated for instance-held global identities was one the decision had been written to avoid.

Before redesigning anything about identity, custody or lifecycle, search the organisation's decision record (the bookshelf's product and strategy collections) and the sibling deployments' own capabilities and docs for the same nouns, and read what the operating deployments already run. A live capability in a neighbouring workspace is evidence of an existing decision even when the package catalog does not carry it.

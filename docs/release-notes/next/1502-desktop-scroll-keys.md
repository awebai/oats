## Added

- **Desktop: scroll back in a terminal with the keyboard.** Shift+PgUp, or
  Ctrl+B then `[`, scrolls back through an agent's output, as the wheel does,
  in every terminal tab. Ctrl+B followed by any other key still reaches the
  agent as both keys. Ctrl+B `[` needs tmux 3.3 or later on the computer the
  agent runs on. The shortcuts window lists the three under Tabs
  ([desktop.md](../desktop.md#copy-from-a-terminal),
  [desktop-keyboard.md](../../packages/desktop/docs/desktop-keyboard.md)).

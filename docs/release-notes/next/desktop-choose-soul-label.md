## Changed

- **Desktop: the command that opens Workspace › Souls is named for what it
  does.** ⌘N / Ctrl+Shift+N, in the command palette and the shortcuts editor,
  now reads **Souls: choose a soul to spawn (Workspace › Souls)**, where it
  read **Spawn instance: choose a soul in Workspace**, so it is not mistaken
  for the sidebar's **Spawn instance** button, which opens Quick Open. Its
  keys are unchanged
  ([Keyboard shortcuts](../../packages/desktop/docs/desktop-keyboard.md)).

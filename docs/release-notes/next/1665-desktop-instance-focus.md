## Added

- **Desktop opens on an instance: `--instance <name>` beside `--dir <deployment>`.** The deployment's window selects that instance in the roster as **Show in roster** does, on a first launch and on a launch while Desktop runs (`open -a "OATS Desktop" --args --dir <deployment> --instance <name>`). It only selects: nothing starts, attaches or is written. Only the `--dir` deployment's own instances count. A name not there yet (a spawn still finishing) is waited for about 30 seconds, then the window says "No instance <name> in this workspace". A value that isn't an instance name, or a name two instances share, selects nothing and says so. Selecting, typing or clicking while it waits drops it ([Opening on an instance](../desktop.md#opening-on-an-instance); [awebai/oats#1665](https://github.com/awebai/oats/issues/1665)). An older Desktop ignores the argument and opens the workspace.

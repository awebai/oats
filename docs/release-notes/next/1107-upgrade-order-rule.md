## Documentation

- **Every release's notes open their Upgrade section with the order of the
  Desktop and the CLI** ([#1107](https://github.com/awebai/oats/issues/1107)).
  A new minor says to install the Desktop first, because the previous Desktop
  refuses the new CLI; a patch says that either order works.
  [The release lane](../release-lane.md) holds the rule for the tag owner.

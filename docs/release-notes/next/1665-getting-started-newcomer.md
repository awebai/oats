## Changed

- **Getting started speaks to a newcomer, asks less and never hands the person a command.** These changes come from newcomer test runs of `oats-getting-started` on fresh machines.
  - **Wording:** the skill talks in everyday words (projects, code, folders, "the setup assistant") and keeps file paths, commands, error codes and raw output to itself.
  - **Step 1** asks three things: what the agents should help with, which projects, and whether this is a fresh start or joining someone's setup. It proposes everything else as defaults: the name, where the shared setup lives, the messaging account, the folder where the agents live (default `<home>/Agents/<workspace>`) and the Desktop. It doesn't ask for the GitHub owner, which comes from the login, or for the harness. When the name changes, every value derived from it changes too.
  - **One confirmation covers every change to the person's computer:** the per-user installs, the PATH line, the Claude channel plugin, folder trust, the Desktop and any missing system package. The skill never runs `sudo` for anything outside that list. A step the harness's permission check refuses runs in a terminal window the agent opens with the command already in it, never as a command the person types.
  - **Linux:** the Desktop's system libraries (ALSA, FUSE 2) are checked before the install.
  - **An existing workspace** names its setup expert `<workspace>-<this machine>-oats-setup-expert`, after the machine's short hostname, so that two members' machines don't collide in the shared team. The invite answer's `awebUrl` is the service URL the join needs, and the machine's messaging root is named for the machine, so the person is asked neither.
  - **The hand-off** tells the person to switch to the Desktop and click the setup assistant, since it has already started and will ask them its first question there. Attaching the person to the workspace's messaging account happens later in the setup, not in its first steps ([awebai/oats#1665](https://github.com/awebai/oats/issues/1665)).

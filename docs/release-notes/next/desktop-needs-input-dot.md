## Changed

- **Desktop: an instance that needs input shows it on its dot.** In the
  sidebar's instance tree, the row's dot becomes the needs-input mark, the
  amber disc with a "!" that the terminal tab and the workspace list already
  show, and the row's "Needs input" label is gone: its second line keeps the
  soul and the repository. A screen reader still hears "Needs input" after the
  name, the hover card keeps the reason and how long it has waited, and a
  collapsed parent still shows "! N below" for the rows it hides
  ([OATS Desktop](../desktop.md#the-sidebars-instance-tree)).

## Changed

- **Desktop: the spawn dialog starts with the Opening instruction.** It is the
  form's first field, and the dialog opens with the cursor in it, after a
  restored instruction's text. The section keys follow the form's order:
  Ctrl+1 / ⌘1 goes to the Opening instruction and Ctrl+6 / ⌘6 to Name. In a
  narrow window, **What will be created** now comes after the form's last
  field instead of above the form. ([Desktop](../desktop.md))

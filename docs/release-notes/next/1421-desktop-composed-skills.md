## Added

- **Desktop: the soul page lists every skill an instance gets.** With OATS
  0.67.0 or later, **Composed for an instance › Skills** lists the soul's own
  skills and the ones its capabilities add, each saying where it comes from
  (**From this soul** or **From** the capability), and the "newer OATS" note
  goes. A capability's skill file opens under its place in the instance home,
  with **Open capability** above it. For a soul on a server, the server's OATS
  must list them too. ([Desktop](../desktop.md))

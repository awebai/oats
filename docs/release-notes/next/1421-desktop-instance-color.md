## Added

- **Desktop: an instance's colour.** Each instance's dot (the sidebar, its
  terminal tab, the command palette, the overview) shows the colour set for
  it: filled while running, a ring while stopped. **Instance: name and
  colour…** in the command palette, or Ctrl+Alt+R (⌥⌘R on macOS), opens a
  small dialog for the focused instance: its name, and **None** plus the six
  palette colours, applied at once through `oats instance color`. Needs OATS
  0.67.0 or later here, and on a server for its instances. The TUI leaves
  Ctrl+Alt+R to the agent. ([Desktop](../desktop.md))

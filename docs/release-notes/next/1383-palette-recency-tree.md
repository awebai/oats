## Changed

- Desktop: the command palette (⌘K / Ctrl+Shift+K) now shows the sidebar's
  tree, with the sidebar's lines and state dots, ordered by the instance you
  focused most recently. A group or a parent moves up when you focus any
  instance under it, and a child stays under its parent. This replaces the
  flat Recent group. The palette still opens on the agent you were on before,
  and the sidebar keeps its own name order (#1383).

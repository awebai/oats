## Added

- **Desktop: the shortcuts window's Most useful names how to scroll back in a
  terminal** ([#1502](https://github.com/awebai/oats/issues/1502)): "Wheel
  up, Shift+PgUp or Ctrl+B then `[`", as the Tabs group's row does. The Tabs
  row's tooltip also says that on another computer the two keys need OATS
  0.69.0 or later there. On Linux and Windows, when a shortcut that works in
  a terminal is bound to Ctrl+B or Shift+PgUp, both rows leave that key out
  and the tooltip names the shortcut
  ([desktop-keyboard.md](../../packages/desktop/docs/desktop-keyboard.md)).

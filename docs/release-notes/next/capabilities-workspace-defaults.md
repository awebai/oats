## Added

- **Desktop: Workspace › Capabilities shows the workspace's defaults.** A new
  **Workspace defaults** section, above Workspace owned, shows what every soul
  starts with unless it turns one off:
  - One column for each core capability, Knowledge, Messaging and Tasks. A
    filled slot shows the capability and where it comes from, and opens its
    page. An empty one says there is no workspace default and each soul
    chooses its own.
  - The other capabilities the workspace gives every soul, under **Also for
    every soul**. One the workspace turned off is struck through.
  - A workspace with no defaults, such as a standalone deployment, says so in
    one line. The search and the repository pills never hide the section,
    and the section jump starts with **Defaults**. With an OATS that does not
    report the defaults, the section is not shown.
- **Desktop: "What capabilities are".** The round **i** button after the
  section jump explains what a capability gives a soul's instances, the three
  places one comes from, and what workspace defaults are. Workspace › Souls
  has the same button, **About souls**, which explains what a soul is
  ([Desktop](../desktop.md#capabilities-and-spawning)).

## Changed

- **Desktop: the Workspace tabs read Souls, Capabilities, Teams, Setup.**
  Teams was first. The page still opens on Souls, and the arrow keys, Home
  and End follow the new order
  ([desktop-keyboard.md](../../packages/desktop/docs/desktop-keyboard.md)).

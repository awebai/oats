## Changed

- **An `ssh://` reference with a user is accepted wherever a repository reference is.** `oats-local.yaml` (`workspace`, `standalone`), `oats-membership.yaml` (`workspace`) and `oats-workspace.yaml` (`members`, and an external soul's pinned `source`) now accept `ssh://<user>@<host>[:<port>]/<path>`, the way the kernel already read it and the way `git@host:path` always was. Before, `oats onboard --workspace ssh://user@host/path` was refused with `E_WORKSPACE_SCHEMA`, while the refusal showed the reference without its user, so it looked valid. A password (`ssh://user:password@…`), an empty user and a second `@` in the host or path stay refused, so in a pinned source the last `@` is always the pin. A package's `git:` reference keeps its own grammar. Existing files need no change ([awebai/oats#1665](https://github.com/awebai/oats/issues/1665)).

## Added

- **Desktop: show only the current workspace.** A toggle before the **+** in
  the Workspace heading hides every row of the list but the current one, for
  working in one workspace at a time. Nothing stands for the hidden ones: no
  "N more" line and no needs-input mark. It is also ⌥⇧⌘O on macOS and
  Ctrl+Alt+Shift+O on Linux and Windows, the same in every chord family and
  from a terminal, and the palette's **Show only the current workspace**. The
  choice is remembered on this computer.

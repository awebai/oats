## Changed

- **Desktop: the sidebar's instance list no longer shows a scrollbar.** On
  Linux the list showed the platform's heavy classic scrollbar when the roster
  overflowed. It now scrolls like the tab strips, with the wheel or the
  touchpad. Moving through the rows with the keyboard (the arrows, Home/End,
  Down from the filter, F6) scrolls the list just enough to show the whole
  focused row, its tools included.

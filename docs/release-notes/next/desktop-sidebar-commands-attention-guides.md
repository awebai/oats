## Changed

- **Desktop: the sidebar's footer no longer has a "commands" button.** The
  leader's chord works as before. The keyboard shortcuts editor lists the
  keys that follow it: open it from the footer's shortcuts button, with
  Ctrl+, / ⌘, or from the palette.
- **Desktop: "Needs input" shows on an instance's second line.** The name
  line keeps the whole name. The mark, or "N below" on a collapsed parent,
  replaces the repository, pull request and branch, which stay in the hover
  card. A home that is being retired or set up keeps its state on that line.
- **Desktop: the sidebar's dotted sibling links sit a little further from
  the lines to children.**

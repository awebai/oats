## Changed

- **Getting started: a new workspace's agents track work in aweb's task list by default, unless the person already uses a tracker.** With aweb, `oats-getting-started` now writes `tasks: { oats.aweb-tasks: { from: package } }` into a new workspace's `defaults`. It writes `tasks: none` when the person's projects already use a tracker, and the setup expert then connects that tracker with them. The skill finds a tracker rather than asking about one: a GitHub repository with at least one issue, open or closed (issues switched on but never used don't count), or a tracker the person names, or ticket keys such as `ABC-123` in recent branch names or commit subjects. It asks one prefilled question only when ticket keys are the only sign. With aweb tasks, it adds aweb's tasks line to the team's instructions, so the team is opted in before its first task (skipped until aweb publishes that line). It also checks that the host wake broker is running at the installed `aw`'s version, and if not, opens the person's own terminal on `oats aweb wake install`. The hand-off names the choice and how to change it, and with a tracker asks the person to leave aweb's task list empty, because one task there opts the whole team in ([awebai/oats#1665](https://github.com/awebai/oats/issues/1665)).

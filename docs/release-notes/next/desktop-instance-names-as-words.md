## Changed

- **Desktop: the sidebar shows an instance's name as words.** Each `-` is a
  space, and the first letter is a capital: `oats-expert-maintainer-lanes`
  reads "Oats expert maintainer lanes", on nested rows and on a spawn's
  pending row too. Only the row's label changes. The hover card, the command
  palette's search, terminal tabs, a screen reader and the CLI keep the real
  name ([OATS Desktop](../desktop.md#the-sidebars-instance-tree)).

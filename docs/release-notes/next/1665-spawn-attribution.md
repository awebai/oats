## Added

- **The kernel records who spawned each instance, and status rows show the human an instance's identity is attributed to.** The feature probe is `spawn-attribution`. Everything here is additive: a home, provider or client without these fields behaves as before.
  - **`spawnedBy`.** A new instance records `spawnedBy: {instance, home}` in `instance.json` and in the `spawned` event. It is `null` when no instance spawned it, and status rows carry the same value. The kernel counts a spawner only when the caller's inherited `OATS_INSTANCE_HOME` is a home of the deployment being spawned into, with a readable `instance.json` that names it, and its session is running. Anything else gives `null`: a person's shell, the Desktop, an automation, a script left over from an ended instance's shell, another deployment's home, or a `--server` spawn whose caller is not a live home on that host. `spawnedBy` is separate from `parentInstance` and `relation`, so an instance's `--relation unrelated` spawn still has a spawner.
  - **`OATS_SPAWNER_HOME`.** Spawn hooks get the spawner's absolute home in this new reserved variable. It is unset when the spawner is `null`. An inherited value is always dropped. A capability should treat a missing value as a person's spawn only when the kernel lists `spawn-attribution`.
  - **`attributedHuman`.** Status rows, local and remote, gain `attributedHuman`. It is the label of the human that the messaging capability attributed its served identity to, through an optional `identity.attribution` (`{mode, human: {id, label}|null, parent: {id}|null}`). Otherwise it is `null`. The kernel reads it from the messaging slot, never from a capability by name. The label is untrusted text, read with the same rule as a waiting claim's message: one line, at most 200 characters, `null` when it contains a refused character. A malformed `attribution` reads as absent and never fails a row. `oats inspect` passes the identity through unchanged.

  See [awebai/oats#1665](https://github.com/awebai/oats/issues/1665), [Spawned by](../desktop-cli-api.md#spawned-by), [Attributed human](../desktop-cli-api.md#attributed-human) and [Commands and hooks](../capabilities.md#commands-and-hooks).

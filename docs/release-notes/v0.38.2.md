# OATS 0.38.2

## Fixed

- **The Desktop's Start and Restart dialog no longer stays open after the
  launch** (awebai/oats#525). Since 0.36.0 the dialog's wait for the
  terminal never recognised the started instance's row, so every Start or
  Restart ended on "no running harness was observed" with the dialog left
  open, while the harness (for Claude Code under channel delivery, its
  development-channels confirmation) waited unseen. The dialog now closes
  as soon as the launch is accepted, and the instance's terminal opens once
  its row is ready, showing whatever the harness shows first. A refused
  launch keeps the dialog with its error.

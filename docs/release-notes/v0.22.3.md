# OATS v0.22.3

OATS now shows every registered server's roster in one place, runs the
knowledge harvest on a remote instance from here, retires exactly the home
you name, and recovers large worktrees on retirement without copying what
the clone already holds. The bundled aweb capability keeps an existing
identity across a re-spawn.

## Remote roster and remote harvest

`oats server roster [--server <id>] [--json]` groups every registered server
and saved route by host and workspace, pulls each group's status once within
a total budget (45 s, 20 s per target; `--budget`, `--per-target`), and
reports what it could not reach instead of waiting for it. Rows carry the
saved route, the running state (true, false, or unknown), pending or failed
retirements, quarantined homes, and routes the host no longer lists.

`oats okf harvest --server <id> --instance <name>` runs the knowledge
package's harvest in that instance's saved home on the host and relays the
package's answer. A registration edited to another target while saved routes
still point at the old one is refused at spawn; `oats server forget` drops a
route whose instance is gone on the host. A routed spawn never overwrites
an existing saved route: an explicit name that has one is refused, and a
generated name that collides reports the new instance without a route.

## Retire the home you mean

Instance names are unique per agent only, so two agents can own an instance
of the same name. `oats retire <name>` now refuses such a name and
`oats retire <name> --home <path>` retires exactly that home. Self-retire and
its deferred completion carry the calling instance's own home. A retire
routed to a server sends the saved route's home when that server's kernel
advertises `retire-home` in its version probe; against an older kernel the
route refuses to retire a name that has twins there.

## Retirement recovery at scale

Recovering an uncommitted worktree used to copy every staged object into
the recovery clone one Git process at a time; a clean 9,500-file tree took
about 19,000 launches and looked hung. Recovery now asks the clone once
which staged objects it lacks and copies only those, and proves at the end
that nothing staged is missing. When independent inspection finds that only
instance-home bytes changed and the worktree carries no work state, the home
is preserved without a repository clone, and the report says so
(`repoCopy.copied: false` with the reason).

## Desktop

Registered servers appear as remote workspaces, projected from the CLI
roster: their souls and instances, spawn with a per-host handoff, terminals
addressed by the exact remote home, and harvest and retire only for
instances with a saved route from this machine. Unknown runtime state is
shown as unknown everywhere it is counted. Retirement reports every
preserved-work path and class, and a spawn whose name collided with an
existing saved route is shown as launched without a route, with the
host-side remedy. The Desktop requires the CLI's `retire-home` feature for
every retirement and never admits a remote home into its local file roots.

## oats.aweb 1.10.0

A soul can declare `identity: { source, takeOver }` and its spawned instance
becomes the retained seat of an existing aweb identity (same did and
address); the legacy home's binding is restored on failure and released on
retirement. The `delivery` setting chooses channel or session wake delivery.
Capability manifests can declare settings with defaults, environment
namespaces, and conditional requirements (`when`, `minVersion`,
`ifInstalled`). The retire report says honestly that a retired alias is not
reusable yet.

## Also

- The version probe's `remote` list gains `roster` and `harvest`; a new
  `features` list carries `retire-home`.
- `oats retire --json` keeps stdout to the envelope (the cross-repo note goes
  to stderr).
- Goldens carry `environmentNamespaces` in the resolved capability projection.
- Viewers for remote instances resolve by home: `session inspect|attach
  --server <id> --home <remote home>` uses the saved route that owns the home
  and refuses a name paired with a different one.
- Deferred retirement retry hints name the exact home.

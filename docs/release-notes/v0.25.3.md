# OATS v0.25.3 — `OATS_SOUL_ID`

Kernel/Pi **0.25.3**. No API change; `features[]` unchanged.

## Kernel

- **`OATS_SOUL_ID`**: a soul's stable identity for capability hooks (`spawn`,
  `retire`, `launch`): `<repo key>#<soul name>` for a workspace soul, the
  realpath of `agents/<name>/soul` for a classic soul. Recorded as
  `instance.json.workspace.soul.id`. OKF 2.1.3 pinned a soul's owner to
  `realpath(home/soul)`, which 0.25.1's per-commit soul cache changes with
  every member commit, so the next spawn was refused `E_OWNER`; OKF 2.1.4 keys
  owners by `OATS_SOUL_ID`.
- **`OATS_SOUL` is the content the home links**: for a workspace soul, the
  per-commit directory, never the swappable `agents/<name>/soul` pointer.

Contract: [workspace module contracts](../design/2026-09-23-workspace-module-contracts.md) §5.2.

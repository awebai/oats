# OATS v0.25.3 — `OATS_SOUL_ID`

Kernel/Pi **0.25.3**. Tag `v0.25.3` → the commit carrying these notes. No API change;
`features[]` unchanged; one additive hook environment variable and one additive
`instance.json` field.

## Kernel

- **`OATS_SOUL_ID`** — a soul's stable identity for capability hooks (`spawn`,
  `retire`, `launch`): `<repo key>#<soul name>` for a workspace soul, the realpath of
  `agents/<name>/soul` for a classic soul. Recorded as `instance.json.workspace.soul.id`.
  Fixes the consequence of 0.25.1's per-commit soul cache found by the first outsider
  rebuild: OKF 2.1.3 pins a soul's owner to `realpath(home/soul)`, which now changes with
  every member commit → the next spawn of the same soul was refused `E_OWNER`. The provider
  half (owners keyed by `OATS_SOUL_ID`, one-time migration of path pins) ships in OKF 2.1.4.
- **`OATS_SOUL` is the content the home links** — for a workspace soul the per-commit
  directory, never the swappable `agents/<name>/soul` pointer (spawn and retire hooks agree).

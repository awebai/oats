# OATS v0.24.1 — workspace adoption, public inspection, captured custody on the home route

Kernel/Pi/Desktop **0.24.1**. Publication is not deployment; every operator still installs, approves and qualifies locally.

## What changed

- **The framework repository joins the Git workspace model.** `oats-workspace.yaml` (workspace `oats-development`) and `oats.yaml` (exports `oats-package`, `capabilities/oats-authoring` and a transitional `souls/oats-expert` edition) are published at the repository root, and the official package repositories publish member indexes. Membership is discovery, not activation. See [Workspaces](../workspaces.md) and [workspace adoption](https://github.com/awebai/oats/blob/v0.24.1/docs/workspace-adoption.md).
- **`oats inspect --request <absolute-json> [--json]`**: read-only inspection of a source, workspace or member. Metadata only: provider payloads and adoption values are omitted, no deployment state or approval is touched, and captured selectors are refused.
- **Captured custody on the home-only session route.** `oats session inspect|input --home H` applies the captured incarnation and custody checks to captured homes and refuses before any transport when the home was replaced. Non-captured homes are unchanged.
- **OKF 2.1.1 pairing.** The mirror and catalog pin `oats.okf@v2.1.1`: Claude and Codex helpers with a complete approved capability closure are accepted; strict Pi still requires an explicit model and the sole-OKF profile.
- **Official marketplace policy.** The reviewed `package-catalog.json` list is the official marketplace; listing is by maintainer-reviewed PR; discoverable is not installed, and installed is not approved. See [the policy as published](https://github.com/awebai/oats/blob/v0.24.1/docs/official-marketplace.md) and the current [official catalog](../official-catalog.md).
- **Kernel setup skill removed.** `skills/oats-portable-setup` is deleted.
- Docs: condensed [contracts](../layers.md).

# OATS 0.46.0

## Added

- **`oats inspect --soul <soul> --instructions` shows the instructions a new
  instance would get.** `souls[0].composedInstructions` is the AGENTS.md a
  spawn of that soul here would write: the soul's own text, then the
  instance-boundary and work-mode blocks and each capability's inject,
  produced by spawn's own composition, with nothing written to the
  deployment. The soul's text and each block are given as ranges into the
  text, named like an instance's `instructions.sources`, so the Desktop can
  show which part comes from where. Without `--instructions` nothing extra is
  composed; with `--home` it is refused. Feature `soul-composed-instructions`.
  `oats doctor --soul` uses the same composition, and its capability markers
  now name the inject home-relative instead of a deleted temporary path.

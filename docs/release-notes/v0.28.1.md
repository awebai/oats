# OATS 0.28.1

## Changed

- **oats.framework 1.2.0 pinned: setup-admin soul skills.** The official
  catalog pins `oats.framework` to `oats-framework/v1.2.0` (tag object
  `e1b39e4b`, commit `9bb956e5`; #210). It brings oats.setup 2.1.0, with the
  new skills `oats-setup-model`, `oats-workspace-config`, `oats-teams` and
  `oats-automations` and a setup injection, and oats.core 2.1.0, current for
  an instance's view. These are what the `oats-setup-admin` soul uses. This
  repository's workspace pins it too; a workspace picks it up by pinning
  `oats.framework: v1.2.0` and running `oats sync`.

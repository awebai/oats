# OATS 0.30.3

## Changed

- **Desktop: the whole app works from the keyboard, with a Linux-sane keymap.**
  Changed Linux and Windows defaults: the command palette is now Ctrl+Shift+P
  on Linux and Windows; close tab Ctrl+Shift+W; split Ctrl+Shift+E /
  Ctrl+Shift+O (close the split Ctrl+Shift+Alt+W); Spawn instance
  Ctrl+Shift+N; the theme cycle has no default chord (on macOS too; the palette
  keeps it). Plain Ctrl+W, Ctrl+K, Ctrl+\, Ctrl+P and Ctrl+B now always reach
  the program in a terminal, and nothing binds Super. New: go to tab
  (⌃1–⌃9 / Alt+1–Alt+9), Ctrl+PgDn / Ctrl+PgUp, ⌘3 / Ctrl+3 for Automations,
  and F6 / Shift+F6 to move between the sidebar, the instances, the main area
  and the instance panel. Your own rebinds are kept. Quick Open (⌘P / Ctrl+P)
  now opens the spawn dialog for the soul you pick, and Esc takes you back to
  where you were; ⌘↵ / Ctrl+Enter spawns from any field, and Tab walks the
  form in the order you see it. Keyboard gaps found in an audit are closed:
  roster rows of unknown state, Independent nodes in the Active overview, the
  Automations row menu, the schedule form and focus lost after switching tabs
  or views. The keymap and the audit are in
  `packages/desktop/docs/desktop-keyboard.md`.

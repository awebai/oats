# OATS 0.30.3

## Fixes

- **Plain `oats` inside an instance is the kernel that launched it.** On a
  machine with two kernels side by side (a global 0.24 for classic
  deployments and a 0.30 prefix install), an agent typing `oats` got whatever
  `PATH` found first: `oats aweb teams` answered `E_UNKNOWN_COMMAND` in a 0.30
  home. Every launch (spawn, `session start`, `session restart`) now writes
  `<home>/.oats/bin/oats`, a link to the launching kernel, and runs the harness
  with `<home>/.oats/bin` first on `PATH`. A restart by another kernel
  re-points it. The recipe records the target as `launch.kernelBin`, and
  `oats status` shows it (`kernel:`) when it is not the running `oats`. A
  launch that cannot write the link fails with `E_LAUNCH_SHIM`. Existing homes
  get the link at their next start or restart.

- **`oats spawn` refuses an argument it does not read.** A positional after
  the soul, or a flag spawn does not know, is `E_BAD_ARGS` naming it, before
  anything is resolved or created. `oats spawn <soul> join=oats` used to be
  accepted and the bare `join=oats` ignored, so the instance joined nothing;
  the refusal now names the form that was meant, `--provider <capability>
  key=value`. A routed spawn (`--server`) is refused on this machine, before
  the server is contacted.

## Changed

- **Desktop: clearer overview lines, a centred rail, pinned Workspace controls.**
  The Active overview draws parent links as smooth curves from a parent's
  bottom to its child's top, with dashed arcs between siblings, in a colour
  that is visible in every theme. The collapsed instance panel's icons sit
  on its centre line. In Workspace, the Capabilities section pills and search
  and the Teams header stay in view while the content scrolls, and scrolling
  to the end of a list no longer moves the whole window.

# OATS 0.42.0

## Changed

- **Desktop has a theme picker (#602).** The theme button and
  Ctrl+Shift+Space (⇧⌘Space on macOS) open a theme picker in the middle of
  the window: the four themes, the current one marked. Choose one with a
  click, Enter or Space; Escape closes it with nothing changed. The shortcut
  works while a terminal has focus too. The theme button now opens the picker;
  cycling between themes stays in the command palette (**Theme: cycle…**). On
  Omarchy, Super+Ctrl+Shift+Space stays Omarchy's own theme menu (it changes
  the computer's theme, which This computer follows); Ctrl+Shift+Space is its
  in-app counterpart and opens Desktop's picker. A shortcut you had already set
  to the same keys keeps them; the shortcuts editor names the clash.

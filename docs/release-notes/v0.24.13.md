# OATS v0.24.13 — schedule history API 3 and the Desktop schedules table

Kernel/Pi/Desktop **0.24.13**. Consumers gate on `oats version --json`
`features[]` names and API integers, never on the version. Shapes are in the
[Desktop CLI API](../desktop-cli-api.md).

## Kernel: `schedule-read-2` (`scheduleHistoryApi: 3`; `scheduleApi` stays 2)

`oats schedule list|show` history had four defects; each is closed under a new
advertised name.

- **A run's identity is when it was scheduled and started, not its outcome.**
  Each run has a stable `runId`; later facts update its one row and
  `transitions[]` keeps the outcome sequence (`["started","unknown","ended"]`
  is one run). Rows from before API 3 are returned with `legacy: true` and
  `runId: null` and are never merged.
- **Bounded, descriptor-safe state.** Both scope files must be regular files,
  are opened without following symlinks, and are read only within a 1 MiB
  budget; over budget is a typed `E_SCHEDULE_STATE_OVERSIZE` refusal. History
  is capped at 50 rows (`history: {status, stored, truncated}`); one job's
  corrupt history never fails the others.
- **Subject truth.** `list` and `show` echo the resolved `scope` and canonical
  `id`; a definition whose own `id` differs from its key refuses
  `E_SCHEDULE_IDENTITY`.
- **Session provenance, not a transcript.** The `transcript` pointer, which
  named a reader that did not exist, is removed. Every run carries
  `session: {instance, home, incarnation, server, delivery}` as known when it
  was recorded.

## Desktop

- **Schedules** view: a compact table (enabled, schedule, target, cadence,
  next run, last reported outcome, actions) with **Recent runs** for the
  workspace, read on entry and on Refresh, without polling. `ended` is not
  shown as success and `delivered` not as consumption. Remote history and
  editing a captured wake are not available. Requires `scheduleHistoryApi: 3`
  and `schedule-read-2`.
- **Security**: the command-running `GET /api/schedules` is removed (405);
  legacy POST `list|show` aliases go through the same strict admission and
  budgets.

## Upgrade

`npm i -g @awebai/oats@0.24.13`, then `oats doctor`.

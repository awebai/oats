# OATS 0.44.2

## Fixed

- **An operator soul may empty its knowledge and tasks slots.** Operator
  coverage (readiness and doctor) excluded a soul that composes `oats.setup`
  when it emptied any slot the workspace fills, so a setup soul with
  `knowledge: none` or `tasks: none` left a permanent `operator-soul-missing`
  or `operator-team-uncovered` warning ("not usable here: … slot-none"). Only
  `messaging: none` now excludes it: an operator keeps the workspace's core
  and stays reachable. The items' shape and codes are unchanged. See
  [Operator coverage items](../desktop-cli-api.md#operator-coverage-items).

# OATS 0.25.8

## Fixed

- **Desktop: quotes are escaped in attribute contexts** (#139).
- **The roster reports an instance where it actually is.** `oats status`
  reports each instance at the directory the kernel enumerated
  (`<soul dir>/instances/<name>`), under that name. An `instance.json` whose
  `home` or `instance` disagrees no longer relocates or renames it; the values
  appear only as `recordedHome` / `recordedInstance`. A hostile or corrupted
  `instance.json` could otherwise make retire, `inspect --home` or the Desktop
  target a path outside the deployment.

## Added

- **Team facts for workspace-model hooks.** Lifecycle hooks of a workspace
  spawn receive `OATS_TEAM_SCOPE` (the deployment directory), `OATS_TEAM_ID`
  (the messaging slot's merged payload `team`, empty when no shared team is
  mapped, meaning "personal"), and new `OATS_TEAM_LABEL`,
  `OATS_WORKSPACE_NAME` and `OATS_WORKSPACE_KEY`. Classic deployments are
  unchanged.
- **Desktop: Capabilities, Sources, sync and approval, onboarding** (#143).
  The Workspace view gains a Capabilities table and a Sources tab, runs `oats
  sync` and approves pending packages only when (id, version, executables
  digest) match the latest sync report (`E_APPROVAL_STALE` otherwise), and
  onboards a picked folder. The 0.24 Deployment inventory and Workspace
  readiness blocks are removed.
- **Desktop: design parity with Redesign v3, brand artwork, and the
  deployment model on kernel JSON** (#137, #128, #126).
- **`oats.aweb` is the workspace messaging default** (#140); the onboarding
  skill makes messaging setup its own step before the first spawn (#141), and
  its next-step hint names `oats-operator-expert` (#134).
- **The OATS repository hosts a workspace-model workspace** (#127), with the
  `oats-operator-expert` and `integrations-expert` souls (#129), and `oats.core`
  and `oats.setup` rewritten for the workspace model (#133).

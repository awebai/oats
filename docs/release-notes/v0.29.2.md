# OATS 0.29.2

## oats.aweb 1.15.0 (catalog pin and bundled mirror)

The catalog and this repo's workspace pin `oats.aweb` to `v1.15.0`, and the
bundled `capabilities/oats-aweb` is the tag's tree.

- **Live receive on joined teams.** An instance's joined teams now receive
  live through the host wake broker. Session homes register the primary
  identity plus every joined identity. Claude and Pi channel homes use aw's
  mixed mode, and Codex keeps polling. Readiness reports each joined team's
  actual mode (`joined-team-receive` or `joined-team-poll-only`, with the
  reason). This needs aw >= 1.36.12.
- **The identity-home scrub (critical fix).** Provider commands and nested
  spawns and retires no longer inherit the caller's `AWEB_IDENTITY_HOME`.
  Inside an instance, that variable made aw refuse cwd-rooted commands, which
  broke roster and join. On retire, it could delete the caller's workspace.
- **Home operations work under the kernel.** `oats operation run
  messaging:teams|join|leave` gets exactly one JSON-v1 envelope, whose `ok`
  agrees with the exit status. The Desktop's teams, join and leave buttons now
  work. A partial multi-label join or leave records every label it completed.
  A failed spawn hands its joined teams to compensation. `oats aweb join`
  refuses resident-grant homes (`E_TEAM_GLOBAL_MODE`).
- **An agent playbook.** The new `oats-aweb` skill carries the playbook, and
  the inject is shorter and points to it. `oats aweb roster --label <label>`
  is new.
- **Deferred to 1.16: per-workspace personal-team enrollment.** It needs a
  per-deployment login and a recorded owner. 1.15 makes no `aw auth` or
  `aw team ensure` call, and the primary team resolves as in 1.14.2. A
  host-set `settings.oats.aweb.roots.personal` is ignored with the readiness
  warning `personal-root-deferred`.

## Desktop

- **Line counts on the Changes rows** (#245, #246). The server passes kernel
  #238's per-file counts through, and each W6 Changes row ends with "+84 −3",
  or "binary". An unknown count (untracked, submodule) and older kernels show
  nothing, never "+0".
- **The Git & GitHub tab counts unresolved review threads** (#247). The tab and
  the collapsed rail button say "Git & GitHub, 2 unresolved review threads".
- **Send N threads to <instance>** (#248, #249). When the instance's PR has
  unresolved review threads, the Pull request card offers to send them to the
  instance.
  - The server composes the text, and the preview shows exactly what will be
    pasted.
  - The text is one line, framed as untrusted input from GitHub reviewers,
    with control, bidi and zero-width characters stripped.
  - It is pasted into the instance's terminal without Enter.
  - A digest of the previewed bytes guards the send: if the threads changed,
    nothing is pasted and the preview refreshes.
- The Desktop still accepts OATS CLIs `>=0.25.8 <0.30.0`.

# OATS 0.36.0

## Added

- **A deployment reports its workspace identity** (feature
  `workspace-identity`, awebai/oats#482). `oats status --json`'s `workspace`
  object now also carries `key` (the workspace host's canonical repository
  key, so every spelling of one repository matches, and the host's key when
  `oats-local.yaml` names a member whose backlink is known), `ref` (the
  reference exactly as `oats-local.yaml` writes it, for display), `keyFrom`
  (`"workspace"`, or `"member"` while a member's host is not known),
  `standalone`, `defaultTeam` (`{label, team}`),
  `teams` (`{<label>: <provider team id> | null}`) and `teamsFrom`. They are
  read offline, so they are there whether the workspace is reachable or not.
  Shared teams come from the workspace file the run read
  (`teamsFrom: "observed"`), else this machine's cached copy at the host
  commit it last observed (`"cache"`, no git process), else nowhere
  (`"local"`: local teams only). `oats server roster --json` relays each
  host's `workspace` object verbatim on its group (from a host before
  0.36.0, the reachability-only object), or `null` from a host that reports
  none. The rule for matching teams across machines (when a
  `null` team is unmapped and when it is unknown) is in
  docs/desktop-cli-api.md, under Workspace identity. A deployment without
  `oats-local.yaml` still has no `workspace` object, and the human-readable
  `oats status` is unchanged. After upgrading, run `oats sync` on each remote
  host (and on any deployment with no instances): the parsed cache belongs to
  the running kernel, so until the deployment observes its workspace again,
  a status that does not read the workspace itself reports
  `teamsFrom: "local"` and its shared default team shows as unknown.

## Changed

- **The Desktop's tabs fit the window, and the selected tab stays in view.**
  Tabs share the tab strip like VS Code's "shrink" mode: each takes at most its
  natural width (still capped at 280px) and they shrink evenly as more open,
  down to 136px; below that the strip scrolls. A shrunk tab keeps the end of
  its name ("oats-…palette"), so tabs whose names share a prefix still read
  differently. The branch gives way before the name, and the full
  name stays in the tooltip and the accessible name. Whenever a tab becomes
  active, a tab closes, or a strip resizes (the window, the sidebar or panel,
  a split), the active tab is scrolled fully into view, in split groups too.
  After the tabs, only Split right and Split down remain. Closing a split
  (⌥⌘W / Ctrl+Shift+Alt+W) and showing or hiding the instance panel
  (⌥⌘B / Ctrl+Alt+B) are on their chords and in the command palette, and the
  panel keeps its own collapse control
  ([desktop-keyboard.md](../../packages/desktop/docs/desktop-keyboard.md#the-command-palette-k)).
- **The Desktop's command palette lists instances like the sidebar and cycles
  with ⌘K.** With an empty query it shows every instance in the sidebar's
  groups, order and indentation, then the commands. A query keeps that tree,
  showing each match under its dimmed ancestors. While the palette is open,
  ⌘K moves down and ⇧⌘K up, wrapping. Enter opens the row and Esc closes, so
  a second ⌘K no longer closes the palette. On Linux/Windows the chord,
  Ctrl+Shift+P, already holds Shift, so ArrowUp moves up there.
- **The Desktop's default monospace font is Inconsolata, bundled with the
  app.** The terminal and the UI's code, paths and shortcut hints use it on
  every machine, ahead of the system monospace fonts. A terminal font you
  already chose is kept. Inconsolata is under the SIL Open Font License 1.1
  ([fonts/README.md](../../packages/desktop/renderer/fonts/README.md)).

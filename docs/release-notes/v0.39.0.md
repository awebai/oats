# OATS 0.39.0

## Added

- **The Desktop shows each workspace's own machines** (awebai/oats#517). With
  a CLI that has `servers-per-workspace` and `server-connect`, a window's
  spawn dialog (**Where to run**) and Workspace › Setup (**Machines**) list
  only the machines whose registration reports that window's workspace key,
  and **Add a machine to this workspace…** runs `oats server connect` (then
  `oats aweb connect` for oats.aweb messaging), showing each step and what to
  do for any that needs you. Without those features the Desktop behaves as
  before. See docs/desktop.md.

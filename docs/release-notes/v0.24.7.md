# OATS v0.24.7 — instance Git observation, soul declarations, and no hollow agents

Kernel/Pi/Desktop **0.24.7** (PR #57). Two additive read-only contracts for the
Desktop (`instanceGitApi: 1`, `soulsApi: 1`), a spawn refusal that closes a
first-team defect, and Desktop views built on them. The contracts are
described in the [Desktop CLI API](../desktop-cli-api.md).

## Kernel

- **`oats instance git <instance> [--home] [--dir] [--json]`** and
  **`oats instance diff <instance> --file <id> --revision <rev> [--index-revision <idx>] [--json]`**:
  read-only Git observation of one instance's work tree. It reports the branch
  the tree is actually on (the spawn-recorded branch as `recorded`, with a
  `drift` flag), status with renames, and upstream and default-branch
  comparisons separately (no upstream is `null`). A diff refuses
  `E_STALE_OBSERVATION` if HEAD, the index or the file moved; reads are bounded
  at 256 KiB. Several homes with one name refuse `E_AMBIGUOUS_INSTANCE`; a
  retired tree is `E_NO_WORKTREE`. The observed tree's repository config is
  treated as untrusted input: external diff, textconv, fsmonitor and hooks are
  disabled, the caller's Git environment and global config are not inherited,
  and no object or index refresh is written (`readOnly` in the response).
- **`oats inspect --json` souls carry their declarations** (`soulsApi: 1`):
  `declarations`, `provenance` (recorded by `oats onboard` from now on; `null`
  means unrecorded), `readiness` (declared sources joined against the payload's
  capability inventory, separate from launchability), and `result.sources`.
- **No hollow agents.** `oats create` declares `oats.core` by default, which
  suppresses the kernel's legacy skills, but nothing activated the replacement,
  so `spawn` produced an agent with no operational curriculum. `spawn` now
  refuses `E_REQUIREMENT_INACTIVE` before creating anything, with the remedy
  (`oats install oats.framework` if needed, then `oats use oats.core --soul
  <name>`) and the opt-out (remove the declaration). `create` states the
  activation step (`next-step` note, `declaredCapabilities` in `--json`).

## Desktop

- A shared contextual right panel (Instance, Git & GitHub, Soul) with a
  collapsed rail, per-workspace preferences and a temporary focus mode.
- **Git & GitHub panel** on `oats instance git|diff`: worktree, branch and
  drift, upstream and base named separately, file counts and rename paths, and
  a bounded read-only diff; stale observations are re-read, never rendered. The
  old background Git collector, which ran Git on every roster poll, is removed.
  The GitHub/PR card is unavailable in this release.
- **Souls and Sources** on the new declarations: recorded provenance
  (`null` renders *Unrecorded*), "Not declared" distinct from "Not reported".
- **Capabilities**: the official catalog via `oats catalog` plus the
  deployment's inventory; override catalogs are labelled; "Add capability"
  copies the exact `oats install <package>` argv and never executes it.
- **Spawn modal** redesigned: two-column layout, grouped soul chooser,
  provider and model with their provenance, and launch configuration restored.
- **Active overview** of the roster, with activity shown as unknown.

The new views need CLI **0.24.7**; an older CLI renders them as unavailable.

# OATS 0.31.1

## Added

- **Faster read verbs, and `--max-age <s>` to reuse recent remote heads**
  (feature `observe-max-age`). `status`, `workspace status`, `souls`,
  `capabilities` and `inspect` start far fewer git processes, cache what
  they parse by commit, and start the members' remote reads together with the
  host's. With `--max-age` they reuse a head observed in the last `<s>`
  seconds and report `observation {observedAt, reused, localRevision}`
  (`localRevision` changes whenever the local configuration read for the
  answer does). See
  [Observation reuse](../desktop-cli-api.md#observation-reuse-feature-observe-max-age-oats-0311).

## Fixes

- **A remote read that times out no longer leaves its ssh or https helper
  running.** The kernel killed git but not the ssh or `git-remote-https` it
  had started, which stayed connected to an unreachable host until its own
  connection gave up. Git now runs as its own process group, and a timeout
  (or the end of the command) kills the whole group.

- **A capability command whose provider dies of a signal exits as the shell
  reports it** (128 + the signal number, 130 for a Ctrl-C), not 1.

- **`oats --help` piped into another program is no longer cut off at 8 KB.**
  The top-level usage (about 20 KB) now arrives whole, including the
  "Observation reuse" section; exit codes are unchanged.

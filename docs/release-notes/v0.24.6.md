# OATS v0.24.6 — `oats catalog` and the first Desktop parity slice

Kernel/Pi/Desktop **0.24.6**. No contract, schema or authority change.

- **`oats catalog [--json]`**: a read-only description of the effective official package catalog: its origin (`bundled` snapshot or `OATS_PACKAGE_CATALOG` override), every package with URL, ref, payload root and the exact `oats install` argv, and the capability-to-package alias map. Nothing is acquired, trusted or fetched. Catalog identity grants no executable trust, a bundled catalog may lag later package releases, and aliases are mappings, not an export inventory. See [the official catalog](../official-catalog.md).
- **Desktop sidebar**: more compact relation guides in the roster, **⌘F** reveals and focuses the filter, **⌘N** opens an explicit soul chooser (never auto-spawns), and shortcut hints follow user rebinds.

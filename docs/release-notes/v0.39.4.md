# OATS 0.39.4

## Fixed

- **`oats session input` no longer reports an unsent message as submitted.**
  After a large bracketed paste, Claude Code could swallow the Enter that
  followed it at once, leaving the text in the agent's input box until someone
  pressed Enter, while the command answered `submitted: true` (#562). Enter
  now waits for the pane to settle, and is judged by whether it changed the
  bottom of the pane (a byte comparison that ignores a redraw at another
  width; the pane's text is never interpreted). A swallowed Enter is resent
  with a backoff, at most 3 in total, and the text is never pasted again. The
  answer gains `verified`: `true` when the comparison judged the Enter, `false`
  when the pane could not be captured (then only one Enter is sent, and
  `submitted: true` keeps its old meaning). When no Enter is taken the answer
  is `submitted: false, verified: true, reason: "enter-not-taken"`; a consumer
  that requires `submitted: true`, such as the aw wake broker, then reports a
  failed delivery instead of a silent one. A call now takes up to about 4 s.
  See [execution targets](../execution-targets.md).

# OATS v0.24.8 — lifecycle plans, readiness, spawn preview, instance events, and guarded Stop/Remove in the Desktop

Kernel/Pi/Desktop **0.24.8**. Tag `v0.24.8` → the commit carrying these notes
(the last code change is `508fda04`, PR #69). The npm tarball's `gitHead` is
the tagged commit; the version-bump commit lands after the tag. All new
contracts are **advertised**: consumers gate on `oats version --json`
`features[]` names and the API integers below — never on the version number,
never by optimistic invocation.

## Kernel — the remaining Desktop-parity seams (K3, K5, K6, K7, K8)

- **Lifecycle plans** (K3, `lifecycleApi: 1`, feature `lifecycle-plans`):
  `oats instance stop <i> --plan|--apply` and `oats retire <i> --plan`, then the
  **guarded apply** `oats retire <i> --plan-revision <rev> --idempotency-key <key>
  [--discard-worktree] [--delete-branch]`. A plan states producer facts (ordered
  targets deepest-first, session/work facts, recorded children, `midTask:
  "unknown"` never inferred) under a 24-hex `planRevision`; apply re-reads and
  refuses `E_PLAN_STALE` (fresh plan attached) when facts moved. Keys replay
  their own receipt instead of acting twice — stop receipts are stored **per
  key**, retire receipts survive the home's removal.
  - **Retention by default** (feature `retire-retention`): a plain retire
    re-homes the worktree to `<workspace>/.agents/worktrees/<repo>/<branch>`
    instead of deleting it; `--discard-worktree` removes; `--delete-branch`
    deletes the branch the tree is **verified** to be on and implies discard.
    Receipt `retention {worktree: retained|removed|absent, movedTo, branch,
    recordedBranch, branchDeleted?, branchDeletionSkipped?}`; a failed move is
    `E_WORK_PRESERVATION_FAILED` with the home kept.
  - **Children first, kernel-owned.** A guarded retire stops the plan's recorded
    children (bounded SIGTERM, never escalated) and retains them; a child still
    running refuses the whole retirement — `E_CHILDREN_RUNNING`, nothing retired.
  - **Branch deletion is bound to the confirmed branch**: re-verified at deletion,
    after hooks (which may mutate the tree); a mismatch deletes nothing and
    reports `branchDeletionSkipped {expected, actual, reason}`.
  - **Ambiguous parentage is reported, never acted on**: parent edges are bare
    names; one that resolves to several homes appears under `ambiguous[]`
    (`plan.ambiguous` on stop, `plan.facts.ambiguous` on retire).
  - A pre-plan CLI does not understand `--plan` and would retire on it; that is
    exactly why the feature is advertised — consumers must gate.
- **Readiness** (K5, `readinessApi: 1`): `oats readiness [--soul] [--home]
  [--verify-signatures] [--policy] --json` — the quartet
  installed · trusted · configured · enrolled, each `pass|fail|unknown|not-applicable`
  with items `{subject, required, reason, producer, evidence, remedy}`;
  `summary.ready` is never vacuous. Signatures are `unknown` unless
  `--verify-signatures` (an explicit one-commit fetch; `verified|unsigned|invalid`
  with the signer named). Enrolled = workspace-member admission.
- **Enforced child policy** (K5): soul `children: {spawn: bool}`, spawn
  `--allow-child-spawns|--no-child-spawns`, recorded as `instance.json`
  `policy.childSpawns {allowed, origin}`; a spawn with `--parent` under an off
  policy refuses `E_CHILD_SPAWNS_DISABLED`. `inspect --json` souls carry
  `declarations.children`; capability rows carry `commit`.
- **Spawn preview** (K6, `spawnPreviewApi: 1`): `oats spawn … --preview --json`
  states the decision — instance name, home, worktree, branch, base `{ref, oid}`,
  runtime/model/launch config, work mode, composition sources, policy — without
  creating anything. `--base <ref>` picks the base; `@native-default` names the
  runtime's own default explicitly.
- **Instance events** (K7, `eventsApi: 1`, feature `instance-events`):
  `oats instance events <i> [--limit] [--since] --json` — typed, producer-
  attributed lifecycle events (spawned, launched, restarted, stopped,
  stop-refused, retire-planned, retired, worktree-retained, branch-deleted,
  child-spawn-refused, recomposed) from the home's log and the workspace's
  retained copy; truncation and unreadable lines are visible, never smoothed.
- **Schedule run history** (K8, `scheduleApi: 2`, feature `schedule-history`):
  schedules report `recentRuns` — settled runs only, producer order, ≤ 50.
- **Instruction refresh** (feature `session-recompose`): `oats session recompose
  --home <abs> [--dry-run] --json` recomposes a **live** home's `AGENTS.md`
  from its current soul with the same composer spawn used; previous text is
  retained beside it, `instance.json` and a `recomposed` event record it,
  nothing is restarted. An operator action for when a role changes and a
  respawn is not possible or wanted.
- Remote workspaces: `oats instance git|diff` reach a remote instance through
  the negotiated route (K1 remote), refusing rather than guessing where no
  route exists.

## Desktop (parity slices 2b and 2c)

- **2b — Connections.** Settings → Connections with an inline "Connect
  GitHub" (device flow through `gh`, credential custody stays with `gh`; the
  auth pane is a closed key set with redaction). The Git & GitHub panel gains an
  observation-bound PR card: informational, correlated to the exact K1
  revision/branch/remote, never authority. Forge connections are an **ADE
  integration**, not a capability.
- **2c — Stop and Remove.** The instance menu offers *Stop…* and *Remove
  instance…*; both open a plan-backed confirmation showing the kernel's exact
  targets, skipped/ambiguous children, session and work facts, the real branch
  (recorded-branch drift noted separately) and retained-by-default choices.
  One guarded local route; the plan is read from the CLI, each confirmation
  gets an opaque reference, the idempotency key is minted on the first
  confirmation and kept for that intent's retries, one apply at a time; lost
  responses are shown as **unknown outcome**, never "no effect". Stale plans
  require a new confirmation; a refused child stop names the child. The old
  unguarded retire route now answers `E_PLAN_REQUIRED`.
- Everything above is **unavailable** (not hidden, not guessed) when the
  installed CLI does not advertise the corresponding feature.

## Also

- Lessons recorded: consumers gate on advertised features, never on
  optimistic invocation; a declaration that suppresses a default must be
  enforced; read-only Git observation is a security boundary.
- Verification budget: one full gate per change is PR CI; locally only the
  affected suites. Desktop-only changes run the Desktop suites plus the
  focused suite.

## Upgrade

`npm i -g @awebai/oats@0.24.8`, then `oats doctor`. Desktops pinned to an
older CLI keep working; new controls appear as the CLI's advertised features do.

# OATS 0.39.3

## Added

- **Desktop: the sidebar shows which agents are waiting on you.** When an
  agent is waiting for a tool approval, a question or an attention request,
  its row shows a "Needs input" mark next to its name. Hover over the row, or
  focus it from the keyboard, to see what it is waiting for, its message and
  how long it has waited. A collapsed parent shows "N below" for waiting agents
  hidden under it. The mark appears only while the agent is running and the
  installed OATS reports `waiting-on-you`. It goes on the next roster refresh
  after the wait ends.

## Fixed

- **Desktop: sidebar instance rows keep their gap when selected or hovered.**
  Each row is meant to paint its fill 2px short of its top and bottom edges,
  leaving a 4px gap between neighbouring fills. The hover and selected fills
  painted over that gap, so a selected row and a hovered row above or below it
  touched. They now stop short of it, in every theme; row height and the tree
  connectors are unchanged.

# OATS 0.32.0

## Changed

- **Routed ssh calls share one connection per host and notice a dead link.**
  Every `--server` call, `server roster` and `session attach --server` runs
  ssh with `ControlMaster=auto`, `ControlPath=~/.oats/ssh/%C` and
  `ControlPersist=60`, plus `ServerAliveInterval=15` and
  `ServerAliveCountMax=3`. The probe, the command and an attached viewer
  ride one authenticated connection. A viewer whose link dies ends within
  about 60 s with a message naming the command to reattach, instead of
  hanging. These options override any `Control*` settings for the host in
  `~/.ssh/config`. When the control socket path would not fit the 104-byte
  limit or has characters ssh reads as syntax, or `~/.oats/ssh` is not
  private to you, calls run with connection sharing off
  (`ControlPath=none`) and the command warns once per server
  ([servers.md](../servers.md#connections)).
- **The version probe is asked once per process** per server and target.
- A server too old for `oats session` is refused with the tmux command for
  the instance's recorded session and window, not a fixed `oats` session.

## Added

- **Any instance on a server is controllable from here, whoever spawned it.**
  `retire --server` and the routed `session` commands (inspect, attach,
  start, restart, upload), `inspect`, `operation` and `launch-config` reach
  an instance with no saved route by `--home`, or by a name the server's
  roster lists once. A name two homes share there is refused with
  `E_AMBIGUOUS`, listing the homes. Roster rows gain `addressable`, and
  `savedRoute` is information only ([servers.md](../servers.md#run-there)).

- **Remote roster rows carry the host's facts.** `oats server roster --json`
  instance rows relay `identity`, `identityAddress`, `teams`, `startedAt`,
  `createdAt`, `model`, `runtimeState`, `parentInstance`, `siblingInstance`,
  `relation`, `relativeTo` and `spawnOrigin` from the host's `status --json`,
  `null` where the host does not supply them
  ([desktop-cli-api.md](../desktop-cli-api.md#the-remote-roster-oats-server-roster---json)).

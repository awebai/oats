# OATS 0.48.0

## Changed

- **The workspace pins oats.framework 1.8.0 and oats.engineering 1.9.0.**
  The official catalog resolves bare `oats.framework` versions to
  `oats-framework/v1.8.0` (oats.support 1.0.0, the support desk role), and
  `oats.engineering` to `v1.9.0`. That adds oats.maintainer's
  `/support-maintainer` skill: a maintainer that serves the support desk's
  tickets. The capability mirrors under `mirrors/` are regenerated from the
  v1.9.0 tag and their trees equal the tag's. Running instances keep what
  they were spawned with; new spawns pick these up after `oats sync`.

- **The workspace and official catalog pin oats.aweb 1.23.1.** The generated
  `mirrors/oats-aweb` payload equals the provider v1.23.1 tag tree. This adds
  verified LOCAL join mapping/default readback and explicit LOCAL identity
  selectors at launch and preview. Existing captured homes do not adopt the
  changes automatically; this pin does not perform sync, restart or live acceptance.

# OATS 0.33.1

## Fixed

- **A git that the system kills is no longer reported as a timeout**
  (awebai/oats#387). A remote read reports `timeout` only when OATS's own
  timer stopped git. When something else kills git (an out-of-memory kill
  during a large fetch, for example), the error now reads `cannot read remote
  <url> (killed): git was killed (signal SIGKILL)`, with `reason: killed` and
  `details.signal`. Before, it said `(timeout)`.

# OATS 0.33.1

## Fixed

- **A group member that ignores SIGTERM and holds no pipe is SIGKILLed after
  the grace again** (a 0.33.0 regression, awebai/oats#386). When OATS ends
  git, it no longer cancels the SIGKILL as soon as git's own output closes:
  it checks the process group until the grace ends. A group seen empty is
  never signalled again (its id may already belong to another process); one
  with a survivor is killed.

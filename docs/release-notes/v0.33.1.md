# OATS 0.33.1

## Changed

- **Installing a soul's modules reads their files without a process per
  file.** `oats spawn` copies each module's files from the remote cache
  through the command's one `git cat-file --batch` reader per repository,
  as the reads and discovery already do, instead of one `git cat-file blob`
  per file. A Desktop developer spawn on this deployment ran 50 processes
  instead of 81 (34 per-file reads became 3 readers). Budgets, digests,
  partial caches and errors are unchanged.

# OATS 0.69.1

Unreleased

0.69.0 was tagged but never published: its release run failed on a macOS-only
test before anything was released. 0.69.1 is the first 0.69 release, and it
carries everything in [0.69.0's notes](v0.69.0.md): session resume, the agent's
pane in a split window, the scroll keys, the waiting row, oats.aweb 1.32.0,
oats.engineering 1.15.0 and oats.framework 1.15.1.

## Upgrade

- **Follow [0.69.0's Upgrade section](v0.69.0.md#upgrade)**: install the
  Desktop first and the CLI second (a 0.68 Desktop refuses a 0.69 CLI). The
  0.69.1 Desktop accepts OATS CLIs `>=0.26.0 <0.70.0`. Every host that shares
  a workspace runs OATS 0.68.0 or later before any of them syncs to
  oats.aweb 1.32.0. Then run `oats status` once before you restart, so the
  session resume sweep knows what was running.

## Fixed

- **The Desktop's tests pass on macOS.** A test of the session resume
  runner compared a working directory without resolving macOS's `/var` →
  `/private/var` link, which failed both macOS Desktop builds of 0.69.0
  (#1590). No behaviour changes.

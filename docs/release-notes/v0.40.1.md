# OATS 0.40.1

## Changed

- **Scheduled jobs default to a host concurrency of five.** The registry stores
  explicit choices only. Legacy stored one migrates to the default once; an
  explicit `oats schedule host install --max-concurrent 1` after upgrade stays
  one. Use `--max-concurrent N|default` and the independent
  `--triggers-max-concurrent N|none` to configure caps through the CLI
  ([#550](https://github.com/awebai/oats/issues/550)). Host status reports both
  caps; triggers remain uncapped by the host unless explicitly limited.

# OATS 0.40.1

0.40.0 was tagged but never published because its Desktop build failed in the release workflow. 0.40.1 is the first published 0.40 release and includes everything in the [0.40.0 notes](v0.40.0.md).

## Changed

- **Scheduled jobs default to a host concurrency of five.** The registry stores
  explicit choices only. Legacy stored one migrates to the default once; an
  explicit `oats schedule host install --max-concurrent 1` after upgrade stays
  one. Use `--max-concurrent N|default` and the independent
  `--triggers-max-concurrent N|none` to configure caps through the CLI
  ([#550](https://github.com/awebai/oats/issues/550)). Host status reports both
  caps; triggers remain uncapped by the host unless explicitly limited.

## Fixed

- **Desktop tests run with only Desktop dependencies installed.** The schedule
  description round-trip integration test now lives in the root suite, where
  kernel dependencies are available. Desktop's standalone release test suite
  retains its unit coverage without importing the kernel.

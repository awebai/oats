# OATS v0.24.12 — instance events API 2 and the Desktop activity popover

Kernel/Pi/Desktop **0.24.12**. Consumers gate on `oats version --json`
`features[]` names and API integers, never on the version. Shapes are in the
[Desktop CLI API](../desktop-cli-api.md).

## Kernel: `instance-events-2` (`eventsApi: 2`)

`oats instance events` had four defects; each is closed under a new advertised
name.

- **Bounded, descriptor-safe read.** Only regular files are opened, without
  following symlinks and verified against the checked file; at most the last
  4 MiB is read (`integrity.sources[].status: ok|absent|refused|tail`).
- **Address history.** `--home` must be a home of the named instance
  (`E_HOME_MISMATCH`); rows of another address are dropped and counted
  (`integrity.foreignRows`). Every row carries `incarnation`, so a recreated
  instance's earlier rows are visible as earlier.
- **`waitingOnYou` is a producer state**, per producer and current incarnation;
  an explicit `false` clears it, earlier incarnations never contribute, and a
  `--limit` window cannot hide a clear. `waitingClaims[]` shows each
  producer's claim; an unknown incarnation admits none. No producer emits it
  in this release, so it is `null`.
- **Provenance and corruption stay visible.** Dedup includes the producer;
  `integrity.unreadableRows` counts torn lines; `count`, `returned` and
  `truncated` are consistent.

## Kernel: retirement fingerprint scope

The `instance.json` field exclusion from 0.24.11 and the `.oats-*` receipt
exclusions also applied to directory work trees and recovery trees. They now
apply to instance homes only; work and recovery trees are fully significant.

## Desktop

- **Lifecycle activity** in the selected-instance popover: an explicit
  *Load / Refresh activity* control shows the kernel's dated events with
  source, integrity, incarnation labels and attributed waiting claims (as
  claims at a time, not current state). A failed refresh keeps visibly stale
  rows. Requires `eventsApi: 2` and `instance-events-2`.

## Upgrade

`npm i -g @awebai/oats@0.24.12`, then `oats doctor`.

# OATS v0.24.12 — instance events API 2 and the Desktop activity popover

Kernel/Pi/Desktop **0.24.12**. Tag `v0.24.12` → the commit carrying these
notes; the version-bump commit lands after the tag. Consumers gate on
`oats version --json` `features[]` names and API integers — never on the version.

## Kernel — `instance-events-2` (`eventsApi: 2`)

`oats instance events` was a working reader with four defects found by the
Desktop engineer's exact-source review; each is closed under a new advertised
name because a strengthened guarantee must be distinguishable from the installed
CLI that lacks it.

- **Bounded, descriptor-safe read.** Each log source is `lstat`ed first; anything
  but a regular file is refused unopened. The open is `O_NOFOLLOW|O_NONBLOCK` and
  the descriptor is `fstat`ed against lstat's device+inode (closes the
  lstat→open swap). At most the last 4 MiB is read by descriptor
  (`integrity.sources[].status: ok|absent|refused|tail`).
- **Address history, incarnation-tagged.** `--home` must be a home of exactly
  the named instance (`E_HOME_MISMATCH`). Rows of another address are dropped and
  counted (`integrity.foreignRows`). Every row carries `incarnation` (the writing
  home's `instance.json.createdAt`); the result echoes the current one, so a
  recreated same-address instance's earlier rows are visible *as earlier*.
- **`waitingOnYou` is a producer state**, per (producer, current incarnation):
  that producer's latest row carrying the field decides, an explicit `false`
  clears, earlier incarnations never contribute, and it is computed over the full
  admitted read so a `--limit` window cannot hide a clear. `waitingClaims[]`
  shows every producer's current claim. **An unknown current incarnation
  (unreadable `instance.json`) admits no claim at all.** Still `null` today — no
  producer emits it.
- **Provenance and corruption never disappear.** Dedup includes the producer;
  `integrity.unreadableRows` counts torn lines regardless of `--since` or the
  window; `count`/`returned`/`truncated` are consistent.

## Kernel — retirement fingerprint scope (K6h)

0.24.11's kernel-field neutrality for `instance.json` — and the pre-existing
`.oats-*` receipt exclusions — were keyed on a root-level *filename*, so they
also applied to directory work trees and recovery trees. Both are now opt-in
(`{ instanceHome: true }`), passed by exactly the four instance-home callers;
work and recovery trees are fully significant. A comparison blind spot (directory
work was already always recovered when non-empty), not a deletion.

## Desktop

- **Reported lifecycle activity** in the selected-instance popover: an explicit
  *Load / Refresh activity* control (no roster or per-card fan-out) shows the
  kernel's dated events with source, integrity (refused/tail/torn/foreign
  visibly incomplete), earlier/unknown incarnation labels, and attributed
  waiting claims as *claims as of a timestamp* — never as current runtime
  authority. Gated on `eventsApi === 2` and `instance-events-2`; two coalesced
  process-wide read slots; one observation retained per open popup; a failed
  refresh keeps visibly stale rows rather than a false empty.

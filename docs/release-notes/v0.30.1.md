# OATS 0.30.1

## Fixes

- **Desktop: an instance-less soul no longer takes the whole roster down.**
  `oats status --json` reports an agent row's `key` as `null` when no instance
  records a workspace soul, as the roster contract documents. That happens for a
  soul directory with no instances: after a spawn preview of a soul that has
  never been spawned, or after its last instance is retired. The 0.30.0 Desktop
  accepted only a string there, so one such row rejected the whole observation
  with `E_CLI_PROTOCOL` ("The installed OATS CLI returned an invalid deployment
  observation"). The Desktop now accepts `null` and still refuses any other
  type.
- **Desktop: a stored workspace selection the server no longer serves** (a
  deleted deployment) locked the Desktop out: every roster refresh refused the
  server's reply as "belongs to a different workspace", and the switcher
  already showed the served workspace as active. A selection that is not
  among the served workspaces is now treated like an empty one: both rosters
  adopt the served workspace and the stored selection is replaced. A
  selection the server does serve, answered with another workspace, is still
  refused.
- **Desktop: terminal tabs are back to native geometry.** 13px system
  monospace, xterm's default line height, and 32px side gutters with no
  vertical inset, as before Redesign v3. The block cursor is one cell tall
  again. A font size you chose yourself is kept.

## Packages

- **oats.engineering 1.3.0** (was 1.1.0 in 0.30.0).
  - 1.2.0: the packaged `code-reviewer` launches on Codex with `gpt-6-astra` by default, a different model family from the developers it reviews. A machine without the `codex` binary gets `E_HARNESS_UNAVAILABLE` when it spawns `code-reviewer`, until it installs Codex or overrides the preference (`oats-local.yaml` `souls.launch`, or `--harness`/`--model` at spawn).
  - 1.3.0: review happens on local branches, before the PR. The developer runs its adversarial loop with the `code-reviewer` on its local branch and hands the reviewed branch to its expert. The expert reviews that branch, and only when it accepts is a PR opened. A returned branch's delta goes back through the same reviewer first.

## Changed

- **Two Desktop souls.** The `oats-desktop-designer` soul is removed.
  `oats-desktop-expert` now owns Desktop's UX and design direction as well as
  its product rationale, and `oats-desktop-developer` builds all of
  `packages/desktop`, including renderer views, styles, themes and copy.
  Running designer instances keep working until they are retired; `oats
  status` reports their soul as no longer present.
- **The legacy Desktop soul trees are removed.** `agents/oats-desktop-engineer`
  and `agents/ux-designer` were no longer offered souls. The
  `oats-desktop-expert` knowledge node carries their durable rationale.

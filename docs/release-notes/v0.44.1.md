# OATS 0.44.1

## Changed

- **Desktop: the instance panel toggles with ⌘I** (Ctrl+I on Linux and Windows), in place of ⌥⌘B /
  Ctrl+Alt+B. As before, it does not fire inside a Linux/Windows terminal, where Ctrl+I is the program's
  Tab. A rebinding you made in Keyboard shortcuts is kept.
- **Desktop: harness badges show recognisable marks instead of letters.**
  Pi's badge is the official pi.dev press-kit mark (MIT; source and licence
  in `packages/desktop/renderer/harness-marks/`), drawn in the theme's
  colour. Claude Code shows an ivory four-pointed sparkle on a terracotta
  tile, and Codex a `>_` prompt on an inverse tile. Both are OATS's own
  drawings, not the official logos. The badge keeps its accessible name
  ("Harness: <name>"), and an unknown harness still shows "?". Every mark
  holds 4.5:1 on its tile in White, Solarized and Dark, and on a stopped
  instance's dimmed row.

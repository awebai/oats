# OATS 0.44.1

## Changed

- **Desktop: the instance panel toggles with ⌘I** (Ctrl+I on Linux and Windows), in place of ⌥⌘B /
  Ctrl+Alt+B. As before, it does not fire inside a Linux/Windows terminal, where Ctrl+I is the program's
  Tab. A rebinding you made in Keyboard shortcuts is kept.
- **Desktop: harness badges show recognisable marks instead of letters.**
  Pi's badge is the official pi.dev press-kit mark (MIT; source and licence
  in `packages/desktop/renderer/harness-marks/`), drawn in the theme's
  colour. Claude Code shows an ivory four-pointed sparkle on a terracotta
  tile, and Codex a `>_` prompt on an inverse tile. Both are OATS's own
  drawings, not the official logos. The badge keeps its accessible name
  ("Harness: <name>"), and an unknown harness still shows "?". Every mark
  holds 4.5:1 on its tile in White, Solarized and Dark, and on a stopped
  instance's dimmed row.
- **Desktop: Capabilities grouped by repository, and a clearer spawn preview.**
  - **Capabilities.** Workspace owned and Repo owned are grouped by the
    repository that defines each capability. Groups are headed like the Souls
    tab: host first, then by name, external sources last. Pills (**All**, then
    one per repository, each with its count) replace the Team and Repo
    dropdowns. The Team dropdown never matched anything, because capability
    rows carry no team.
  - **Spawn dialog.** **What will be created** leads with the instance name and
    its home, then works in, harness and model, team, relationship and runs on.
    The launch-prompt policy is a note after them. Capability rows keep their
    chips on a second, left-aligned line, and the column stacks its facts when
    narrow. Cancel and Spawn stay together on one line at every width.
  - **Dropdowns.** Every dropdown shares one themed style, and each theme
    declares its `color-scheme`, so open lists and scrollbars follow light or
    dark.

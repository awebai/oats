# OATS 0.51.0

Unreleased

## Added

- **`oats tui` (preview): a terminal client (#855).** `oats tui` is a
  full-screen, keyboard-only client for people who work in terminals and on
  machines with no display. It ships inside the `oats` package: there is
  nothing else to install. **It is a preview, and this version draws the
  frame only**: it shows the frame, answers `?` (help) and `q` (quit), and
  reads nothing from the kernel yet. The views arrive in later releases, and
  while it is a preview its screens may change without notice. It leaves
  preview when the readers it shares with the Desktop are in their shared
  home, a person has used it for a working day and both maintainers agree.
  - **What it does to your terminal** is a closed list, restored on every way
    out a process can handle (quit, an internal error, SIGINT, SIGTERM,
    SIGHUP, SIGQUIT) and across `Ctrl+Z` and `fg`: raw mode, the alternate
    screen, the cursor hidden, autowrap off and bracketed paste on. It
    switches on no mouse or focus reporting and no keyboard protocol, writes
    no title, clipboard sequence or bell, and uses only your terminal's own
    sixteen colours (`NO_COLOR` is honoured). After SIGKILL no process can
    restore a terminal: `reset` is needed (inside tmux, `tput rmcup` too), and
    nothing is left in tmux.
  - **Text it did not write never reaches the terminal raw.** The screen
    draws only the TUI's own words and text that passed the display filter it
    shares with the Desktop, so a name or a message cannot write a control
    sequence.
  - **Without a terminal** on stdin and stdout, or with `TERM` unset or
    `dumb`, it exits 1 with one line on stderr naming `E_NO_TERMINAL` and
    draws nothing. `oats tui --json` is refused with `E_BAD_ARGS`: it is
    interactive, and `oats status --json` is the machine view.
  - `oats pane` still refuses, and its message now names `oats tui` beside
    the Desktop.
  - No JSON answer, configuration key, hook or lock changes, and
    `oats version --json` lists no new feature: nothing gates on this word.
    See [OATS TUI](../tui.md).

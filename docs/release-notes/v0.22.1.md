# OATS v0.22.1

A reliability release. The Desktop compatibility band (`>=0.22.0 <0.23.0`)
already covers this kernel; no Desktop rebuild is needed.

## Fixes

- **`oats create` in a fresh scope no longer crashes.** It bootstraps the
  roster root at the enclosing repository and reports it (`agentsRoot` in
  `--json`); the `mkdir agents` workaround is no longer needed.
- **Spawn preflights executables and compensates every failure.** The runtime
  binary, tmux (when launching), and the task input are checked before any
  mutation. After the spawn hooks, one compensation path runs retire hooks,
  removes and verifies Git topology, stops any created window, and retains the
  home with its receipt for a retryable `oats retire` when cleanup cannot
  finish.
- **The turn record's stream lock is ownership-safe and bounded.** The lock
  carries an owner token, staleness is judged from the holder's liveness, only
  the owner releases it, and acquisition has a deadline. Known limit: a pid
  reused after a reboot makes an abandoned lock read as held until an operator
  removes it.
- **README claims match the implementation.** Captured turns are
  content-addressed, not signed; projected aweb mail and chat keep their
  original signatures.
- **Bundled capabilities match their published tags.** The bundled official
  packages are byte-identical to the tagged payloads (`oats.okf` 1.4.1,
  `oats.aweb` 1.8.0, `oats.jira` 1.0.0, `oats.linear` 1.0.0, `oats.authoring`
  1.0.0, `oats.review` 1.2.0 from `oats.dev` 1.0.0), and tests enforce the pin.
- A release with nothing to bump now finishes instead of failing.

## Known limits in this release

- The `oats.okf` 1.4.1 harvester runs in Pi, so a Pi-runnable model is needed
  even for Claude Code workers; its default model assumes the `github-copilot`
  provider, so set `harvest-model` to a model your Pi can run.
- A Claude Code worker's first launch can stop on the folder-trust prompt and
  on the aweb channel plugin's confirmation; attach to the tmux session and
  answer them.
- Retiring an instance leaves its aweb alias reserved on the server; use a
  fresh `--purpose` for successors.
- From a workspace root, `oats spawn` needs `--dir <repo>`.
- `oats status` lists the retirement-baselines directory as an instance,
  retire leaves that baseline file behind, and `oats retire --json` prints a
  bare object rather than the schema-v1 envelope.

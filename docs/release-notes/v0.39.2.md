# OATS 0.39.2

## Added

- **oats.cloning 1.0.1**, a new official package (catalog entry, workspace
  member and pin, and the bundled mirror): clone an instance for a new goal.
  `oats cloning request <source>` spawns the package soul
  `oats.cloning/cloner`, which reads the source and writes a curated,
  redacted brief, then spawns the clone with it attached and a fresh
  identity. The clone gets no raw transcript, notes or work content. See
  [instance cloning](../design/2026-10-01-instance-cloning.md).
  - The framework's oats-expert, oats-kernel-expert, oats-desktop-expert,
    integrations-expert, oats-operator-expert and oats-setup-admin souls take
    it (`oats.cloning: { from: package }`); there is no workspace default.
  - The workspace pins it as `git:github.com/awebai/oats-cloning@v1.0.1`
    until every deployment's CLI carries this catalog entry; then the pin
    becomes the bare `v1.0.1`.
  - 1.0.1 over 1.0.0 (the first pin on main): secret assignments are
    redacted in any case and as JSON or YAML keys (`password=…`,
    `client_secret: …`, `"PASSWORD": "…"`), a quoted value to its real
    closing quote. The README states what redaction does not catch, and that
    under `delivery: channel` a Claude Code cloner or clone waits at Claude
    Code's development-channels confirmation until a human answers it.
  - Operators: run `oats sync` to lock the package; new spawns of those
    souls get the capability. Running instances keep what they were spawned
    with.

## Changed

- **Desktop: terminal text in the White and Solarized themes renders at the
  stroke weight of a native macOS terminal with font smoothing.** Chromium
  draws dark text on a light background lighter, so these themes' terminal text
  looked fainter than the same font in a native terminal. Each theme now sets
  its own text weight; Dark is unchanged, and bold text stays bold.

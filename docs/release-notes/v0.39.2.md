# OATS 0.39.2

## Changed

- **Desktop: terminal text in the White and Solarized themes renders at the
  stroke weight of a native macOS terminal with font smoothing.** Chromium
  draws dark text on a light background lighter, so these themes' terminal text
  looked fainter than the same font in a native terminal. Each theme now sets
  its own text weight; Dark is unchanged, and bold text stays bold.

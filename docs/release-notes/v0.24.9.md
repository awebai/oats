# OATS v0.24.9 — readiness pins, side-effect-free spawn preview (API 2), process-group safety, Desktop Readiness view

Kernel/Pi/Desktop **0.24.9**. Consumers gate on `oats version --json`
`features[]` names and API integers, never on the version. Shapes are in the
[Desktop CLI API](../desktop-cli-api.md).

## Kernel

- **Spawn preview API 2** (feature `spawn-preview-2`, `spawnPreviewApi: 2`).
  An API 1 preview could write (an event on the parent, a started Herdr
  backend, an imported soul) and nothing bound a later spawn to it. An API 2
  preview touches nothing, success or refusal. `spawn --agents-root <abs>`
  binds the exact root. The preview returns a `decision {instance, home,
  branch, base, revision}`, and `spawn --expect-decision <rev>` refuses
  `E_DECISION_STALE` with the fresh decision on any drift, creating nothing.
  Native probes share one bounded preflight budget. **Gate on API 2.**
- **Readiness**: `configured` reflects effective activation (a declared but
  disabled capability fails and says so); data-only capabilities report trust
  `not-applicable`; items are typed, and `summary.byCapability[]` regroups them
  with `ownReady` and `ready`; `subject.selector` echoes the arguments; an
  unreadable member document is `unknown`; `readiness --home <captured>`
  refuses `E_UNSUPPORTED_MODE`. Signature verification (feature
  `readiness-verify`) is bounded, ignores global Git config, allows https and
  ssh only, and reports a closed `signature.failure.code`.
- **Process-group safety.** A timed-out child's process group was killed with
  `process.kill(-child.pid)`; when the spawn itself failed (for example, a
  missing binary) the pid was 0 and the signal hit the caller's own process
  group, so `oats readiness --verify-signatures` without `git` could kill the
  operator's shell, tmux or Desktop backend. Every kill site now refuses
  non-positive pids.
- **OKF 2.1.3** is mirrored and pinned in the official catalog: per-cause
  `check` reasons, a named remedy when a soul has no `okf.json`, and retired
  drained sources switch their `okf-<id>` job off.

## Desktop

- **Readiness** view: a Workspace header entry and first-run invitation
  showing the readiness quartet with items and remedies (display only). Verify
  signatures and Enrol are shown unavailable with the reason. The Capabilities
  view shows effective readiness per scope.
- **Route classification** is decided once from the normalized pathname, so
  dot-segment, percent-encoded, backslash, tab and CRLF aliases cannot skip a
  route's guard.
- **Spawn modal** uses the preview (API 2) for the instance name, home,
  worktree, branch and resolved base; *Suggest* asks the kernel for its default.
  Preview-only choices block legacy submission instead of being dropped.

## Upgrade

`npm i -g @awebai/oats@0.24.9`, then `oats doctor`. Desktops on an older CLI
show the new controls as unavailable.

# OATS 0.25.9

A pins-only patch: the kernel is unchanged since 0.25.8.

## Updated

- **`oats.aweb` 1.12.1** (catalog pin + bundled copy; #145). The messaging
  root is explicit: `settings.oats.aweb.root` / `roots[team]` in
  `oats-local.yaml`. On a workspace-model deployment it defaults to the
  deployment directory and is never searched for upward. Error texts name the
  workspace-model remedies. In local mode an instance gets `AWEB_IDENTITY_HOME`,
  so `aw` works from any directory. `binding-check` answers
  `needs-configuration` before spawn, with one problem per missing item (no
  messaging root; no team), and an unmapped workspace team label fails the spawn
  closed instead of inheriting the root's active team.
- **`oats.okf` 2.1.5** (catalog pin + bundled copy; #148).
  - Every configured base must be usable at spawn. A shallow base is refused
    with `E_BASE_SHALLOW`; clone, fetch and checkout failures are
    `E_BASE_UNAVAILABLE` naming the alias, repository, step and reason, never a
    raw `ETIMEDOUT`.
  - A missing `OATS_SOUL` is `E_OATS_SOUL_MISSING`; there's no fallback to the
    home's soul link.
  - Refusing an owner rename names both souls and both remedies.

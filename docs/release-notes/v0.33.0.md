# OATS 0.33.0

## Changed

- **OATS fetches only what it reads from a remote** (awebai/oats#384). A
  commit comes with its trees and its files up to 64 KiB; a larger file is
  fetched when a read or a module needs it. The first spawn from a large
  workspace host downloads megabytes instead of its whole tree (tsm: 13 MB in
  3 s, instead of 2.4 GB in 6.5 minutes). A server that cannot serve partial
  fetches (a default `git daemon`, an old self-hosted git), or a local git
  older than 2.45, gets whole trees as before, with one `oats: warning` per
  repository.

- **oats.engineering 1.4.0** (catalog and workspace pin, and the bundled
  mirrors): the developer's loop REQUIRES loading `/understand-the-spec` and
  `/execution-strategy` before implementation.

## Fixed

- Fetching a commit into the remote cache may take 10 minutes instead of 30 s, so
  the first spawn from a large workspace host no longer fails with `cannot read
  remote … (timeout)`; the timeout error names the fetch and the elapsed time
  (awebai/oats#362).

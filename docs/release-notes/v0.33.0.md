# OATS 0.33.0

## Changed

- **oats.engineering 1.4.0** (catalog and workspace pin, and the bundled
  mirrors): the developer's loop REQUIRES loading `/understand-the-spec` and
  `/execution-strategy` before implementation.
- **Faster module and soul materialization.** A spawn, sync or package
  resolution that copies a module or soul tree reads every file through the
  command's one `git cat-file --batch` reader per cache repo instead of
  starting a `git cat-file blob` process per file. The files, their modes and
  the recorded digest are unchanged, and so are the budgets and error codes.

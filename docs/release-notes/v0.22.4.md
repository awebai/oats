# OATS v0.22.4

Two fixes found by running the wake broker and the record-fed harvester as
real host services, the oats.aweb 1.10.1 floor, and the managed lead soul.

## Session commands under a service locale

launchd starts services without a UTF-8 locale, and tmux then replaces the
tab delimiters in its list-panes output with underscores, so every session
inspection from the wake broker reported an invalid pane. The shared session
helper now runs tmux in UTF-8 mode (`-u`), which preserves the delimiters
regardless of the service locale and makes typed input UTF-8-safe.

## Record windows without the search index

`recall --thread --json` used to open the record's SQLite search index just
to extract turn text, and a capture indexing a large session cache could hold
that database locked for longer than the harvester waits. Window reads now
come from the journals alone; the search index opens only for indexed
search, show and reindex.

## Bundled: oats.aweb 1.10.1

Session-mode delivery now requires an installed Claude Code channel plugin
to be `aweb-channel` 1.7.9 or later (as it already required `@awebai/pi`
0.3.10): an older plugin starts its own channel server beside the wake
broker and can fetch a message before the broker delivers it.

## Managed operating-lead soul

`agents/lead/soul` is tracked: the operating lead's role instructions and
two knowledge notes (runtime and messaging ownership; where rollout state
lives), ready for a retained-identity binding at its cutover.

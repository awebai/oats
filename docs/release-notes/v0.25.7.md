# OATS 0.25.7

## Fixed

- **A v2 deployment is a configuration boundary.** The ancestor walk over
  legacy `oats-config.yaml` levels stops at the directory holding
  `oats-local.yaml`, so a deployment inside another scope no longer inherits
  the outer scope's files, and `oats inspect` no longer reports the outer
  checkout as its `scope.workspace` or lists its files in `scope.chain`.

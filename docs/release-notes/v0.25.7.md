# OATS 0.25.7

## Fixed

- **A v2 deployment is a configuration boundary.** The ancestor walk that
  composes legacy `oats-config.yaml` levels now stops at the directory holding
  `oats-local.yaml`. A deployment created inside another scope (a scratch
  deployment under an operator's workspace, a fixture under a repository) no
  longer inherits the outer scope's files, and `oats inspect` no longer names
  the outer checkout as its `scope.workspace` or lists the outer files in
  `scope.chain`. Found by the Desktop engineer's Phase F study.

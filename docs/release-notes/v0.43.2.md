# OATS 0.43.2

## Fixed

- In a terminal tab, ⌘C or Edit › Copy with nothing selected no longer
  copies an earlier selection: the clipboard is left as it was
  ([#695](https://github.com/awebai/oats/issues/695)). A copy from the tab's
  banner or from an input in it is no longer replaced by the terminal's
  selection.

# OATS v0.22.13

Terminal essentials for the Desktop and one kernel operation behind them:
attachments reach the agent as a path, never as typed input.

## Attachments (kernel)

`oats session upload --file <local> --home <abs>` copies a file into the
instance home's private `.oats-attachments/` directory (0700, file 0600,
`name-2` when the name is taken) and answers `{path, bytes, sha256}`. With
`--server <id> --instance <name>` (or `--home`), the same saved route as
`session attach` is resolved, the remote must advertise the new
`session-upload` feature, and the bytes travel on ssh stdin into
`oats session receive --home <abs> --name <file>` on the execution host,
which reads stdin event-driven, enforces the 64 MiB kernel bound before
writing anything, allocates the destination exclusively so simultaneous
uploads never overwrite each other, refuses a symlinked or redirected
attachments directory, and reports the path only after the bytes are
synced. The local side refuses the answer unless size and sha256 equal the
local file's. Each side buffers the whole file up to the bound; a remote
file is never a local path over SSH. Upload never sends terminal input.
`oats version --json` lists `session-upload` in `remote` and `features`.
The CLI's temporary tmux viewer session hides its status line; the agents'
session and the operator's tmux settings are untouched.

## Desktop

Drop files or paste clipboard images onto an agent terminal: the paths are
inserted into the draft with bracketed paste and no Enter, local files in
place, clipboard images saved privately under the app's data directory, and
remote terminals uploaded through the installed CLI first (both CLIs must
advertise `session-upload`; a failed transfer leaves the draft unchanged and
never inserts a local path). Up to 16 files and 25 MB per drop. The viewer's
tmux status bar is hidden. Ctrl+Tab stays tab navigation inside terminals
on macOS while other Ctrl chords stay with the program. An already-open
terminal fills an empty split without a second attach; separators resize by
pointer or keyboard. Guide: docs/desktop.md, "Attach files and screenshots".

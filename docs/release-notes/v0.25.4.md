# OATS 0.25.4

Patch release: one kernel fix.

## Fixed

- **Quarantine retry never re-ran the owed retire hook on a workspace-mode
  home.** When a required spawn hook fails and its compensation is
  incomplete, the kernel keeps the home with a cleanup descriptor
  (`.oats-rollback-incomplete.json`). `oats retire` trusted the pre-hook
  `instance.json` stub over that descriptor, so every retry reported that the
  retire hook did not run, and only `--force` could remove the home (leaving
  the provider's external state to clean by hand). The retry now reads the
  descriptor whenever the live record is not a complete spawn record: the owed
  hook runs, and the home is removed once it succeeds.

No contract changes. `oats version --json` is unchanged apart from the version.

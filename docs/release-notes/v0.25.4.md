# OATS 0.25.4

Patch release: one kernel fix found by an operator rehearsal on 0.25.3.

## Fixed

- **Quarantine retry never re-ran the owed retire hook on a workspace-mode
  home.** When a required spawn hook fails and its compensation is incomplete,
  the kernel retains the home with a cleanup descriptor
  (`.oats-rollback-incomplete.json`). Module materialization had already
  written a pre-hook `instance.json` stub (`{ modules, providers,
  resolutionRevision }`), and `oats retire` trusted that stub over the
  descriptor — so `meta.repo` was undefined, the retry reported *"retire hook
  <cap>: did not run on this retry"* and *"cleanup descriptor lost its context
  repo"* on every attempt, and only `--force` could remove the home (leaving
  the provider's external state to be cleaned by hand). The retry now reads
  the cleanup descriptor whenever the live record is not a complete spawn
  record; the owed hook runs, the home stays while it fails, and is removed
  once it succeeds. Regression test in `test/spawn-workspace.test.mjs`.

No contract changes. `oats version --json` is unchanged apart from the version.
